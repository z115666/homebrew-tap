# z115666/homebrew-tap

[English](README.md) · **Español**

Tap de Homebrew con las herramientas de [z115666](https://github.com/z115666).

## Instalación

```bash
brew install z115666/tap/aimarkers
```

O, en dos pasos:

```bash
brew tap z115666/tap
brew install aimarkers
```

## Fórmulas

| Fórmula | Descripción |
| --- | --- |
| [aimarkers](https://github.com/z115666/aimarkers) | Detecta marcadores de IA en código, documentación, webs, imágenes (C2PA, IPTC, EXIF) y repositorios Git. Opcional: `brew install c2patool` para verificar las firmas C2PA |

## Seguridad

Cada fórmula fija la versión y el hash SHA-256 del código fuente a un commit concreto. El workflow de este repositorio instala, prueba y audita cada fórmula en macOS en cada cambio.
