# z115666/homebrew-tap

Tap de Homebrew con las herramientas de [z115666](https://github.com/z115666).

## Instalación

```bash
brew install z115666/tap/aimarkers
```

O, en dos pasos:

```bash
brew tap z115666/tap
brew install aimarkers
```

## Fórmulas

| Fórmula | Descripción |
| --- | --- |
| [aimarkers](https://github.com/z115666/aimarkers) | Detecta marcadores de IA en código, documentación, webs y repositorios Git |

## Seguridad

Cada fórmula fija la versión y el hash SHA-256 del código fuente. El workflow de este repositorio instala, prueba y audita cada fórmula en macOS en cada cambio.
