# z115666/homebrew-tap

**English** · [Español](README.es.md)

Homebrew tap with the tools of [z115666](https://github.com/z115666).

## Installation

```bash
brew install z115666/tap/aimarkers
```

Or in two steps:

```bash
brew tap z115666/tap
brew install aimarkers
```

## Formulae

| Formula | Description |
| --- | --- |
| [aimarkers](https://github.com/z115666/aimarkers) | Detects AI markers in code, documentation, websites, images (C2PA, IPTC, EXIF) and Git repositories. Optional: `brew install c2patool` to verify C2PA signatures |

## Security

Each formula pins the version and the SHA-256 hash of the source code to a specific commit. This repository's workflow installs, tests and audits every formula on macOS on every change.
